# Spinel

Spinelは、毎日生成される有限枚数のカードを1枚ずつ処理する、個人向けのRSSリーダーです。

SNSのタイムラインや一般的な未読管理のように情報を無限に積み上げるのではなく、その日に読む範囲を明確にし、未読負債を残さず終えられることを重視します。
